# Project artwork

Generated on 2026-10-09 using Codex's built-in image generator, one project at a time. These are concept illustrations, not application screenshots or proof of implemented interfaces. Prompts use the project's documented features and avoid customer data, metrics, and brand logos.

All 11 covers are exported as 1600 × 900 WebP images in `aabanrehman-main/public/uploads/projects/`, named `<project-slug>-concept.webp`. Each project JSON selects its cover using `image` and describes it using `imageAlt`. Pages CMS exposes these files under Project images and the Project cover / thumbnail selector. Replace a cover there when real screenshots are available.

Open Design's local daemon was unavailable. Brag was reviewed but video production was not used: this repository contains portfolio descriptions rather than the actual code/UI of each application.
